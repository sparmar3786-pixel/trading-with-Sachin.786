Formula & interpretation
Short option: P/L = premium received − intrinsic value at expiry.
Long option: P/L = intrinsic value at expiry − premium paid.
CE intrinsic = max(Spot − Strike, 0); PE intrinsic = max(Strike − Spot, 0).
Break-even: CE = Strike + premium; PE = Strike − premium.
Margin is collateral/risk requirement; it is not the maximum loss.
